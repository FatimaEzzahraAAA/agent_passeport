# Agent RAG - Démarches Administratives Marocaines (Passeport)

## 🎯 Sujet et Corpus
Le sujet choisi est **le passeport marocain** (demande, renouvellement au Maroc et à l'étranger, CNIE).
**Pages utilisées (6 fichiers texte dans le dossier `corpus/`) :**
1. Certificat de coutume marocain (contexte mariage)
2. Renouvellement du passeport marocain (Maroc et consulats)
3. Obtenir une carte d'identité et un passeport à l'étranger
4. Premier passeport biométrique marocain
5. Contacter l'Ambassade du Canada au Maroc
6. Contacter l'Ambassade d'Espagne au Maroc
